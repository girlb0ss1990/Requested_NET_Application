# ChequeWriter

Converts a numeric cheque amount into New Zealand/British wording.

```text
1234.56
→ One thousand, two hundred and thirty-four dollars and fifty-six cents
```

## Projects

- **ChequeWriter** — console app + `ChequeAmountConverter`
- **ChequeWriter.Tests** — xUnit automated tests

## Run

```powershell
dotnet run --project ChequeWriter
dotnet test
```
